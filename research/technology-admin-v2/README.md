# Matcha Manita Integration Administration v2

Standalone, read-only administration preview backed by a snapshot of the existing verified provider registry. Open through a static server. Includes search, category filtering, provider detail inspection, official source links, keyboard shortcuts and safe DOM text rendering. No secrets stored in browser or claims of live vendor integration.

## Test checklist
1. Serve this directory using a local HTTP server.
2. Verify 39 providers load and categories populate.
3. Search 'Metrc', then clear search with Escape.
4. Select 'Cannabis POS' category and inspect a provider.
5. Confirm documentation opens in a new tab with rel=noopener noreferrer.
6. Check narrow mobile viewport and browser console.
